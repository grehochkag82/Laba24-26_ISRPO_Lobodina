## Реализованное приложение: Менеджер задач (Task Manager)

Простое, но полностью функциональное веб-приложение для управления списком задач.  
Все данные сохраняются в браузере с помощью `localStorage` – после обновления страницы задачи не исчезают.

### Функциональные возможности

- **Добавление задачи** – через кнопку "Добавить" или нажатие клавиши `Enter`.
- **Отметка о выполнении** – чекбокс переключает статус задачи; выполненная задача визуально выделяется (зачёркнутый текст, другой цвет рамки).
- **Удаление задачи** – кнопка "Удалить" с подтверждением удаления.
- **Фильтрация** – показывает все / только активные / только выполненные задачи.
- **Статистика** – отображает общее количество задач и число выполненных.
- **Постоянное хранение** – используется `localStorage`, данные не теряются при перезагрузке страницы.

### Технологии и приёмы ES6+, применённые в коде

| Концепция | Где использована |
|-----------|------------------|
| Классы (ES6) | Класс `TaskManager` инкапсулирует всё состояние и поведение приложения. |
| Приватные поля (идея) | Используется соглашение с `this._tasks`; в полной версии можно применить реальные приватные поля `#tasks`. |
| Стрелочные функции | Во всех обработчиках событий, в методах `map`, `filter`, `forEach`. |
| Деструктуризация | При работе с объектом задачи (например, `{ id, text, completed }`). |
| Шаблонные строки | Для генерации HTML-разметки каждой задачи. |
| Методы массивов | `push()`, `filter()`, `find()`, `map()`, `forEach()`. |
| Тернарный оператор | Для условного присвоения класса `completed` и состояния чекбокса. |
| `localStorage` + `JSON` | `getItem()` / `setItem()`, `JSON.stringify()` / `JSON.parse()`. |
| Модули (опционально) | В дальнейшем код можно разбить на модули (`taskManager.js`, `ui.js`, `storage.js`). |
